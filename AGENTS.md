I'm Kenny. You are my agent. We will be working together a lot, so I thought it might be worth introducting myself.

I love to build. I focus on building complex things as simple as possible. I love to find ways to reduce complexity when solving problems.

I want to share some of preferences so we can be more aligned when we work together. These are intended as guidelines not hard rules. If the developer (me) specifies something that goes against these guidelines, let me know before proceeding.

### Preferences

Don't use a cream or off-white background, italic accent words in headings, numbered "01 / 02 / 03" section labels, monospace labels, or pill-shaped buttons.

### Layout

- `src/content/` all page copy as typed data (site, tools, data releases, news) plus `formatDate`/`formatNumber`. Import from `@/content`. Never hardcode copy in the page; fix or extend it here.
- `src/app/(home)/` the homepage at `/`: a field of stems, one per hundred genotyped accessions, that sways under the pointer. `layout.tsx` loads its font, `_components/` holds the canvas and stem data, `wind.css` its contrast-ordered inks. Earlier design explorations live on the `combined-previews` branch.
- `src/app/hairline/` Hairline figure experiments.
- `src/components/ui/` shadcn components. Add more with `bunx --bun shadcn@latest add <name>`.
- `src/components/theme-toggle.tsx`, `image-placeholder.tsx` shared helpers.
- `src/components/palette/` Sanzo Wada palette system. `<PaletteProvider design shortlist defaultId>` wraps the page and sets `--p1`..`--p4` plus `--p1-fg`..`--p4-fg` (black or white text for each). Use them as `bg-(--p1) text-(--p1-fg)`. `usePalette()` gives hex values for canvas and SVG. `<PalettePicker />` is the last element of the page.
- `src/content/wada.ts` the 159 colours and 348 combinations, generated by `bun scripts/wada.ts`.
- `public/` images. Only `fairybread.png` exists so far; other tools use `<ImagePlaceholder />`.

### Homepage rules

- Render every section with the ids from `sections` in `@/content` (`about`, `tools`, `data`, `news`) plus a footer with `funding`.
- Take every palette colour from `--p*` or `usePalette()`. Dark mode is class based (`dark:` variant); dark backgrounds are true black and text white.
- `bun run build` must pass.
