## Examples of news and updates

10/08/2026 - Added wheat stripe rust QTLs from Tong et al. 2024 (Triticum aestivum - IWGSC_RefSeq_v2.1 - QTL - Rust meta QTLs - Tong 2024) and Micheni et al. 2026 (Triticum aestivum - IWGSC_RefSeq_v2.1 - QTL - Stripe Rust meta QTLs - Micheni 2026).
30/07/2026 - Added genotypes for 32,656 Wheat AGG Plant genetic resources (https://doi.org/10.7910/DVN/MOBTA8) genotyped by the AGG Strategic Partnership; updated in-silico genotype calls generated for assemblies in the 10+ Wheat Genomes project (Walkowiak et al. 2020) using Brioche v2; and updated marker positions for the Wheat Barley Infinium 40k BeadChip in IWGSC RefSeq v2.1 and IWGSC RefSeq v1.0 using Brioche v2.
17/06/2026 - New Pretzel version v3.11.0 released! Includes new functionality for displaying and filtering null alleles from genotype data. Additional new datasets loaded include: 27,242 barley AGG plant genetic resources (https://doi.org/10.7910/DVN/LXU0WD) genotyped by the AGG Strategic Partnership; in-silico genotype calls generated for assemblies in the Barley Pangeome v2 (Jayakodi et al. 2024) using Brioche v2; and updated marker positions for the Wheat Barley Infinium 40k BeadChip in Morex v3 using Brioche v2.
08/09/2025 - Added genotypes for 5,635 Field pea AGG Plant genetic resources (https://doi.org/10.7910/DVN/A6WGYS) genotyped as part of the AGG Strategic Partnership, anchored against the Cameor v2 assembly
14/08/2025 - Added genotypes for 6,308 Lentil AGG Plant genetic resources (https://doi.org/10.7910/DVN/T0TDAS) anchored against the CDC Redberry genome assembly (Lcu.2RBY) and an additional 1,813 Chickpea AGG Plant genetic resources (https://doi.org/10.7910/DVN/ECQ4NC) anchored against the CDC Frontier gnm3 assembly, all genotyped as part of the AGG Strategic Partnership
25/07/2025 - New Pretzel version v3.9.0 released! New features enable further integration of passport data via Genolink. Full list of new features here
25/05/2025 - New Pretzel version v3.8.0 released! Full list of new features in docs and here
30/04/2025 - New Pretzel functionality now available in release v3.7.3! Users can now search genotype data for accessions carrying user-defined haplotypes. See the new Use Case Finding genotyped accessions carrying a specific haplotype for more details
16/01/2025 - Added genotypes for 11,071 Chickpea AGG Plant genetic resources (https://doi.org/10.7910/DVN/SQFKJW) genotyped as part of the AGG Strategic Partnership, anchored against the CDC Frontier gnm3 assembly
01/11/2024 - Added the 10+ Wheat Genomes from Walkowiak et al. 2020, including de novo gene annotations (White et al. 2024), Wheat Barley 40k v1.1 mappings and an example of how it can all be used in User Story 3 - From SSRs to pan genomes with Pretzel: Two decades of wheat yield QTLs on chromosome 7A
23/10/2024 - Pretzel v3.0.0 released! This includes the VCF Search use case (see the documentation on how to use it here) and a range of improvements and enhancements
17/09/2024 - Added User Story 2 - Filtering AGG wheat accessions for stripe rust resistance gene Yr34/Yr48
23/08/2024 - Added genotypes for 12,606 Hexaploid Wheat AGG Plant genetic resources (https://doi.org/10.7910/DVN/CRSI0B) genotyped as part of the AGG Strategic Partnership, anchored against the IWGSC RefSeq v2.1 assembly
15/08/2024 - Added genotypes for 13,989 Barley AGG Plant genetic resources (https://doi.org/10.7910/DVN/H6SNVM) genotyped as part of the AGG Strategic Partnership, anchored against the Morex V3 assembly.
